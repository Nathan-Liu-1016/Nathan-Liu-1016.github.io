What I've Built

The data foundation

A cloud lakehouse on Azure Databricks and Azure SQL — medallion architecture, configuration-driven ingestion from files, APIs, and cloud feeds, every load validated and reconciled before it reaches production. Replaced legacy on-premises servers with 100% verified data parity.

The reporting platform

A centralized web platform covering operations and financials for every location — built for 1,100+ employees, each seeing only what they're permitted to see. Purpose-built visuals that tell each location's story at first glance; pages that answer in under one second.

AI in production

An assistant that turns plain-English questions into governed queries and returns trusted answers in seconds — unreliable answers never run. Nightly AI-written summaries on every report page, grounded only in verified numbers. Trusted data first, AI second.

Vendor replacement

In-house web applications that replaced paid vendor platforms: a company-wide forms system (11,000+ records migrated, reconciled to the cent against $142M) and a review-management platform unifying 86,000+ reviews with AI-drafted, human-approved responses.

Owning the data beats renting it.

How I Work

Listen first. Brief, high-level requests become finished products with minimal direction — and many tools began as needs I recognized before anyone asked.

Fix at the source. Every feed is validated and reconciled before production. Problems are fixed where they start, never masked in reporting.

Build lean, but scalable. A small team, no oversized contracts — and every system designed to take the next location, source, and request without a rebuild.

Speak both languages. Engineers get architecture; executives get cost, savings, and timelines. Translation is the job.

Secure by Design

From the outside

  • Company single sign-on with MFA on every application
  • Secrets kept in a vault — no passwords in code
  • Encrypted connections everywhere; every request identity-verified

On the inside

  • Role-based and row-level access: 2,400+ employees, each seeing only what they're permitted to see
  • Every change written to a permanent audit trail
  • Nothing AI-drafted goes out without human approval; every release passes review and gated dev → staging → production controls

Trust is a feature. It is designed in, not added later.
